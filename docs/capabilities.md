# 能力与边界

本页描述当前 Android 0.8.1 源码；实际效果取决于设备、模型资产、光照与画面内容。

| 能力 | 当前行为 |
| --- | --- |
| 目标检测 | 默认 YOLOE-26n 固定 90 类提示，设置保留 YOLO26n；类别数不等于同等识别可靠性 |
| 环境语义 | SegFormer 提供墙面、楼梯、台阶、杆柱、栏杆及家具等证据；自动提醒按类别资格与时效门禁开放 |
| 家具提醒 | 概览覆盖更多家具；新增床/冰箱提醒依赖已核验的 384 模型，退到 256 时不继承资格 |
| 中文提醒 | 固定中文音频与动态 TTS；事件去重、抢占、静音、过期取消 |
| 空间候选 | 描述左/中/右地面连续性，无通行指令 |
| 候选带 | 实验预览层，真实地面 Mask 裁切；证据不足或过期不画，真机阳性显示验收尚未完成 |
| 墙面距离 / 接近 | 仅保留研究证据；不默认播报米制距离或确定的接近结论 |
| ARCore | 当前应用不使用 |
| 路径规划 | 不提供完整路线、人体净空保证、自动绕障或安全通行结论 |

实时模型与环境提示不依赖用户开启研究图层。环境状态和原有风险等级独立，因此“NONE 风险”与“前方检测到墙面”可以同时存在。

更多实现细节与逐版本证据见 [Android 资料](../android/docs/README.md)。
