# 常见问题

## 没有提醒

先确认正在感知、摄像头权限正常、未静音且媒体音量可听。模型可能正在启动、连续确认、负载降级，或没有获得足够的新鲜证据。持续目标已经提醒过时也不会不断重复。没有声音不等于前方没有障碍。

## 没有候选带

候选带需要唯一、连续且新鲜的地面证据。地面不在画面下部、未知区域较多、障碍覆盖、多个方向相近、转向或结果过期都可能使它消失。不要通过放宽时效或将未知区域视为空地来强行显示。

## 中文声音不可用

检查系统 TTS 的中文语言包和离线支持。固定提示有本地音频降级；“描述周围”的动态长句需要可用的中文 TTS。查看应用的语音状态，勿将文本生成当作声音播放成功。

## 安装失败

使用 `adb devices -l` 检查设备与授权。签名不一致或版本回退可能阻止覆盖安装；保留原包和设置，按[发布与回退](../development/releasing.md)处理，不默认卸载。

## 源码可以构建，但没有识别

Git 不包含模型权重。核对 ONNX 文件、模型清单和 SHA 契约，见[模型准备](../development/models.md)。不要取消哈希验证来绕过不匹配。

## 卡顿或内存占用高

关闭不使用的模拟器和研究服务，先保留目标主链。研究图层的隐藏不代表关闭推理；辅助模型由调度策略降频或降级。构建默认限制为单 worker，避免同时运行多个大型实验。
