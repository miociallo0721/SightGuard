# 语音与隐私

## 本地处理

Android Manifest 不声明 INTERNET 权限；摄像头、目标检测和语义模型在设备上运行。进入后台或停止感知会释放相关资源。文件分析通过系统文件选择器读取用户选择的内容。

桌面网页默认绑定 `127.0.0.1`。模型、依赖与公开数据的首次准备可能需要联网，这与应用运行时的图像分析分开。

## 中文音频

固定提醒有对应的本地预合成中文音频。动态 TTS 由设备上的系统服务提供；如需完全离线朗读，请在系统 TTS 设置中选择中文离线声音。TTS 服务的网络行为不由 SightGuard 的网络权限控制。

没有可用的离线动态中文 TTS 时，完整环境描述可能只能显示文字，不会用通用音频假装朗读了全文。应用静音不会修改系统全局音量或 TalkBack 设置。

## 诊断与导出

开发者工具、桌面研究脚本和手动导出可产生图像、检测记录、日志与设备信息。默认忽略的目录并不意味着内容不敏感。共享前删除不必要的画面和标识，不要将私人素材、密钥、模型缓存或设备日志加入 Git。
