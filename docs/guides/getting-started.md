# 安装与首次使用

## Android

需要 Android 8.0 或更高版本、可用摄像头和音频输出。辅助模型会根据负载降级。

1. 获取交付方提供的 APK，并对照[版本与交付](../releases.md)核验文件哈希。Git 克隆不包含 APK，目前没有托管在仓库 Releases 中的安装资产。
2. 在手机上正常安装，或连接已授权 USB 调试的设备后执行：

   ```powershell
   adb devices -l
   adb -s <设备序列号> install -r <APK路径>
   adb -s <设备序列号> shell am start -n org.sightguard.app/.MainActivity
   ```

3. 打开应用，按系统提示授予摄像头权限。默认开始感知；若页面显示已停止，点击“开始感知”。
4. 在静止环境中确认中文声音和静音/停止操作可用，再了解[能力边界](../capabilities.md)。

## 主要操作

- **描述周围**：总结当前有效的检测与环境语义。
- **静音提醒 / 恢复提醒**：控制应用语音。
- **停止感知 / 开始感知**：停止或启动摄像头与模型。
- **设置**：调整自动开始等选项，进入开发者工具或本地文件分析。

“当前有效提醒”反映当前证据；“最近播报”只是历史记录。淡蓝灰候选带如出现，仅表示局部地面证据，文字会标明“通行未确认”。

## 更新与回退

同包名、同签名的新版本通常可通过 `adb install -r` 更新并保留设置。不要为解决安装问题直接卸载，否则会丢失应用数据。低版本包可能无法直接覆盖高版本，数据保留回退方式见[发布指南](../development/releasing.md)。

当前 0.8.1 交付曾因测试清理失败保留自动开始关闭的设置。点击开始感知即可运行；若希望以后打开自动运行，在设置中恢复自动开始。
