# 尚未解决的问题

核对日期：2026-10-12；基线 `b3d0aeb`。P0 表示不能据此作产品可靠性或安全能力承诺，P1 表示必须在面向普通用户发布前处理的工程 / 体验工作。研究默认关闭是隔离措施，不是算法问题已经修复。

## P0-01 环境结构仍有真实误识别和漏检

0.4 真实选例中，夜间倾斜楼梯被误识别为 wall 并实际播报墙面；单级台阶和路缘未识别出 step121；细杆、部分立柱和围栏漏检。选例不构成随机准确率评估。

当前措施：STEP 自动提醒关闭；保留失败，未全局降低阈值。下一步需要独立语义标注、弱光 / 台阶 / 细杆负例及场景分组评测，检查持续确认和组件质量的收益，不能只挑成功图片。依据：[0.4 真实模型记录](../../android/docs/accessible_awareness_v04.md#真实输入与模型结果)。

## P0-02 墙面距离与接近尚未达到自动提醒条件

米制误差跨场景差异明显，无手机卷尺测距校准，无可靠部署域距离区间。TUM 700 帧接近结果全弃权，真实前移墙面正例不足；低纹理、关联失配和旋转解释均限制输出。

当前措施：距离 / 接近语音关闭，不以深度数值波动直接触发接近，不输出速度或 TTC。公开数据可以补充模型对照，不能补齐实体手机已量测场景。依据：[米制研究](../../android/docs/metric_corridor_research.md)。

本轮 Metric3D 在 NYU 24 场景 GT wall 上 MAE 约 0.304m，但 TUM 预测 wall 区域仍未全面胜出；PC 推理约 422ms，尚未移植或测试 Android。子集诊断不能证明部署域距离区间可靠，见[新评测](dataset-evaluation-20261012.md)。

## P0-03 局部候选尚未证明是真实行走地面

已有 24 条支持记录集中在同一贴海报平面；地面语义和连通性不足以证明人体可通行。没有可靠身体朝向、手机姿态、净空宽度或安全通道真值。

当前措施：严格 D 组门禁保留，结果仅 CANDIDATE_ONLY，不自动给出行进 / 转向建议。需要独立地面标签、非地面平面负例、标定几何和未知区域评估；GT 只能用于评价，不能作为算法输入冒充视觉能力。

本轮补充 NYU 独立地面标签，0.55 阈值下评估 floor precision 0.8162，`reception_room_0002` 仅 0.1642；未调整阈值掩盖失败。仍缺少人体可通行真值，32 张 still 严格 D 全弃权。

## P0-04 PC 长会话事件保留未有界化

`src/sightguard/decision/events.py` 将事件标记 RESOLVED 后仍保留在 `events` 字典，`live_events()` 每次扫描 / 排序历史。已核对当前代码仍存在此问题。它可能增加长会话内存和处理开销，不能据此推断具体手机 PSS。

Android `core/AssessmentEngine.kt` 已在导出结束快照后移除 RESOLVED 事件，不能把 PC 问题一概归给手机。长期活跃事件的历史 track ID 等仍需检查上限。

修复应在保留结束快照、递增事件 ID、恢复语义、finish 输出和日志可重放性的前提下有界化；需与原核心回放对照，不能定时清空会话状态。当前文档整理不擅自修改该核心。

## P0-05 缺少独立的产品风险效果与使用者验证

UrbanEgo 首批八段视频来自同一次拍摄，120 秒开发数据，标注仍为 draft。历史规则提醒密度不是实际起播次数或误报率。没有跨拍摄会话的已审核风险测试集、重要风险召回 / 无效提醒 / 重复 / 延迟闭环，也没有视障使用者验证。

需要独立来源分组、人工审核提醒机会、记录生成到实际 onStart 的完整抑制原因。单元测试、检测框和深度图都不能替代这些指标。依据：[真实数据开发集](../real_world_benchmark_v01.md)、[提醒诊断](../alert_behavior_diagnosis.md)。

## P1-01 时间同步与推理速度限制证据可用性

既往 nova12 相机时间源 UNKNOWN，不能安全视为与 IMU 精确同步。原相对深度真机约 0.9 秒，通常超过 500ms 语音证据期限。SegFormer 低频和源龄门禁可能使短暂目标来不及确认。

不延长 TTL 掩盖旧结果；需要设备实测捕获 / 接收 / 完成 / 消费时间、快速转向负例及串行调度优化。新米制模型手机性能尚未测得。红米旧版用户报告 23 FPS 不代表当前实验包性能。

## P1-02 提醒效用、动态中文描述与无障碍覆盖不足

静音、抢占、过期或繁忙可使有效事件不播报。固定中文音频已验证，但动态描述依赖设备离线中文 voice；缺少时只显示文本。TalkBack 大字体专项在 AVD 完成，nova12 厂商读屏、混音体验及视障用户操作流程未完整验证。

不能把“未提醒”表达为安全；需要真实用户流程、屏幕阅读器 / 应用音频共存及重要新事件等待预算测试。

## P1-03 可复现安装与正式发行流程未完成

没有仓库级 CI、正式签名发行和独立干净克隆验收。模型导出及部分开发脚本依赖本机路径和测试资产，构建成功不能证明新克隆的 APK 可推理。稳定调试包约 225MB，米制实验包约 325MB；默认关闭研究仍会增加安装体积。

需要核验资产准备流程、生成模型清单、干净环境构建、受控签名、升级 / 回退及设备支持策略。CI 和包体拆分未在本次文档整理中实现。

## P1-04 仓库许可与发行材料未闭环

尚无仓库整体 LICENSE；SegFormer checkpoint 的独立再分发许可未核实，YOLO / 辅助模型 / 数据许可不能仅由上游代码许可推断。未经用户确定，不替项目选择整体许可证。

正式发布前应完成来源和第三方清单、数据署名、模型再分发审查、隐私说明与实际发行渠道，见[发布要求](releases.md#发布前要求)。

## P1-05 分支、历史说明与演示入口仍需逐步收敛

主目录仍有未提交 PC / UI 修改；0.4 基线、研究分支和本轮提交独立保留。本文档整理不会擅自合并或覆盖主目录。旧报告继续保留原时间和结论，当前说明集中到 README / docs 索引，避免把历史架构当作当前状态。

本轮已修正 PC CLI 的 ui 帮助，将默认演示页与可选研究控制台区分。网页演示方向与正式事件反馈边界仍需进一步改善，并保持研究来源可解释；不能把演示路径包装成安全导航。
