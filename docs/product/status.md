# 当前能力与验证范围

核对日期：2026-10-12。代码基线为 Android 0.4 `4a1fdfb` 和独立研究提交 `b3d0aeb`。本文描述有证据支持的范围，不把工程功能的存在等同产品可靠性。

## 用户能力

**已实现并有既往 Android 验证：** YOLO 目标检测、规则风险事件、墙面 / 楼梯 / 杆柱 / 栏杆存在提醒、前台自动感知、静音、主动停止、本地视频分析、固定中文离线音频、简洁主界面和开发者工具。

0.4 稳定包在 nova12 最终回归 27 项通过，真实照片包含 80 次模型推理、10 次环境自动提醒实际起播；15 种固定环境方向资源均有 `onStart` / `completed`。另有实时 CameraX 墙面提醒及用户中文听感反馈。这些是限定版本和输入的验证，不是整体召回率或误报率。

**部分验证：** TalkBack、200% 字体、横竖屏和窄屏专项在 AVD 完成；nova12 未完成 TalkBack 专项。三次真机启停有资源释放和 PSS 记录，不能替代长时间泄漏、续航或热稳定性测试。

**能力不足：** 单级台阶 / 路缘真实图片未输出有效 step121，自动提醒关闭；细路灯杆、部分立柱和围栏存在漏检；夜间倾斜楼梯曾被高置信度误识别为 wall 并错误播报墙面。楼梯方向不判断。

## 研究能力

既往米制深度使用官方 Depth Anything V2 Metric Small，Hypersim 室内和 VKITTI 室外权重，输出按预测光轴 Z 深度解释。原 Depth Anything V2 Small 是相对逆深度，大值相对更近，不能直接变成米。

本轮新增 Metric3Dv2 Small PC 对照：100 个 TUM 冻结帧、32 个 NYU 独立场景；NYU 24 个评估场景的 GT 墙面 MAE 约 0.304m，但 TUM 预测墙面 MAE 仍差于 Hypersim 280。没有目标手机测距校准或新模型 Android 验收，不启用距离播报。完整数据范围和误差见[本轮评测](dataset-evaluation-20261012.md)。

既往 TUM RGB-D 五个室内序列共 700 个冻结样本有真实深度与位姿来源，但没有墙面 / 地面语义真值。Hypersim 280 的“预测墙区域 MAE”依序列约 0.11–1.84m，不能将最好序列误差当作通用精度。约 ±2.11m 的描述性误差带未经部署域校准，不启用距离播报。

墙面接近研究在该批 700 帧全部 ABSTAIN。明确向前平移且墙面已确认的真实正例不足，不宣称区分旋转与接近成功。IMU 时间源未知时不伪造精确跨源融合。

局部候选有 24 条支持记录，但都覆盖同一海报 / 板面场景，没有通过真实地面候选验收。严格 D 组 700 帧全部弃权。没有 SAFE、PASSABLE、人体净空、路线指令或米制通道宽度。

新增 NYU 真值诊断的 floor 像素 precision 为 0.8162，最差评估图为 0.1642；32 个独立 still 的候选状态为 30 证据不足、2 并列，严格 D 全弃权。单图没有时间确认，不当作动态候选召回评价。

## 证据等级

1. 合成 / 单元测试：验证数据结构、几何计算、边界和事件规则。
2. 真实模型 / 公开数据集：验证实际推理，有真值才计算对应误差。
3. Android 设备：验证实际 ORT、CameraX、声音起播、时效和资源。
4. 实体手机已量测场景 / 使用者评估：验证部署视角、参考距离、人体几何及可用性。

等级分别报告。公开 RGB-D 数据不能验证 ARCore 手机运行、胸前手机净空、续航或真实用户安全。正式代码链路仍是功能预览，不表示已达到正式产品质量。
