01 / ABOUT THE GLASSES

一副眼镜，连接视觉与感知。

我们希望让视觉信息，以更多方式被理解。
从摄像头到反馈模块，每一个环节都围绕“感知前方”展开。

CAPTURE

摄像头采集

从佩戴者的视角获取前方画面，作为视觉模型的输入。

→
UNDERSTAND

模型识别与判断

识别已支持的物体类别，结合画面位置生成提示建议。

→
FEEDBACK

语音与震动反馈

通过喇叭传递信息，用镜腿一端的马达节奏补充提示。

02 / BUILT WITH PURPOSE

用简单的交互，传递重要信息。

把复杂留给技术，把清晰留给使用者。

01

看见前方物体

模型识别行人、车辆等内置类别，展示目标框与置信度，识别效果可以直接观察。

02

让提示听得懂

将方向建议转成简短语句。网页可点击试听，便于讲解喇叭提示的设计思路。

03

让提醒有触感

用不同节奏表达提示类型。一端马达通过节奏区分左右，网页展示编码方式。

04

让过程可解释

每个建议附带画面依据。识别不足时明确显示未知，保留结果与验证记录。
